# 📖 AMC 10 核心高频英文数学词汇（50 词速查）

对于初次参加双语/全英文数学竞赛的中国学生，这 50 个词汇覆盖了试卷中 95% 以上的专业术语障碍。

## 一、 几何类（Geometry，最容易被单词卡住的分类）

| 英文词汇 | 中文含义 | 常见搭配 / 考查语境 |
| :--- | :--- | :--- |
| **Perpendicular** | 垂直的 | Perpendicular bisector（垂直平分线/中垂线） |
| **Parallel** | 平行的 | Parallel lines cut by a transversal（两平行线被截线所截） |
| **Hypotenuse** | 直角三角形斜边 | In a right triangle, the hypotenuse is opposite to 90° |
| **Leg** | 直角边 / 等腰三角形腰 | Legs of a right triangle / isosceles triangle |
| **Trapezoid** | 梯形 | Isosceles trapezoid（等腰梯形） |
| **Parallelogram** | 平行四边形 | Area = base × height |
| **Rhombus** | 菱形 | Diagonals are perpendicular bisectors of each other |
| **Equilateral** | 等边的 | Equilateral triangle（等边三角形，面积 $\frac{\sqrt{3}}{4}s^2$） |
| **Isosceles** | 等腰的 | Isosceles right triangle（等腰直角三角形 :1:\sqrt{2}$） |
| **Diagonal** | 对角线 | Length of diagonal of a polygon |
| **Tangent** | 切线 / 相切的 | Line tangent to a circle at point $ |
| **Secant** | 割线 | Secant line intersecting the circle at two points |
| **Chord** | 弦 | The longest chord is the diameter |
| **Radius / Radii** | 半径（单数 / 复数） | Radii of concentric circles（同心圆半径） |
| **Diameter** | 直径 | Diameter =  \times$ radius |
| **Inscribed** | 内接的 / 内切的 | Triangle inscribed in a circle（圆内接三角形） |
| **Circumscribed** | 外接的 / 外切的 | Circle circumscribed about a square（外接圆） |
| **Collinear** | 共线的 | Points , B, C$ are collinear |
| **Concurrent** | 共点的 | Three altitudes are concurrent at orthocenter |
| **Altitude** | 高线 | Altitude to the hypotenuse |

## 二、 数论类（Number Theory，OI 选手的强项分类）

| 英文词汇 | 中文含义 | 常见搭配 / 考查语境 |
| :--- | :--- | :--- |
| **Prime** | 质数 / 素数 | Prime number, prime factorization（质因数分解） |
| **Composite** | 合数 | Composite number > 1 with > 2 divisors |
| **Divisor / Factor** | 因数 / 约数 | Number of positive divisors of $ |
| **Multiple** | 倍数 | Common multiple, least common multiple (LCM) |
| **Greatest Common Divisor (GCD)** | 最大公约数 | Also known as GCF (Greatest Common Factor) |
| **Coprime / Relatively Prime** | 互质的 | $ and $ are coprime if $\gcd(a, b) = 1$ |
| **Remainder** | 余数 | What is the remainder when ^{2026}$ is divided by 7? |
| **Modulo / Congruence** | 模运算 / 同余 |  \equiv b \pmod m$ |
| **Quotient** | 商 | Division algorithm: Dividend = Divisor × Quotient + Remainder |
| **Integer** | 整数 | Positive integer（正整数），Non-negative integer（非负整数） |
| **Parity** | 奇偶性 | Parity argument（奇偶性分析，odd/even） |

## 三、 代数类（Algebra）

| 英文词汇 | 中文含义 | 常见搭配 / 考查语境 |
| :--- | :--- | :--- |
| **Arithmetic Sequence (AP)** | 等差数列 |  = a_1 + (n-1)d$，Common difference $（公差） |
| **Geometric Sequence (GP)** | 等比数列 |  = a_1 r^{n-1}$，Common ratio $（公比） |
| **Polynomial** | 多项式 | Degree of polynomial, leading coefficient |
| **Root / Zero** | 根 / 零点 | Real roots, distinct roots（互不相同的实根） |
| **Quadratic Formula** | 求根公式 |  = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$ |
| **Discriminant** | 判别式 | $\Delta = b^2 - 4ac$ |
| **Coefficient** | 系数 | Coefficient of ^3$ in the expansion |
| **Absolute Value** | 绝对值 | $|x-a|$ represents distance on number line |
| **Monotonic** | 单调的 | Strictly increasing / decreasing sequence |

## 四、 组合与概率类（Combinatorics & Probability）

| 英文词汇 | 中文含义 | 常见搭配 / 考查语境 |
| :--- | :--- | :--- |
| **Permutation** | 排列 | Order matters: (n, k) = \frac{n!}{(n-k)!}$ |
| **Combination** | 组合 | Order does not matter: $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ |
| **Distinct** | 互不相同的 | Choose 3 distinct integers |
| **Inclusive / Exclusive** | 包含在内 / 排除在外 | Integers from 1 to 100 inclusive (包含 1 和 100) |
| **Probability** | 概率 | Favorable outcomes / Total possible outcomes |
| **Expected Value** | 数学期望 | Linearity of expectation（期望的线性性质） |
| **Fair / Unbiased** | 公平的 / 无偏差的 | Fair standard six-sided die（均匀六面骰子） |
| **Simultaneously** | 同时地 | Two coins are tossed simultaneously |
