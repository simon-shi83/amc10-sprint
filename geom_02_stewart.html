定理二：斯特瓦尔特定理与阿波罗尼奥斯中线模型

求解任意塞瓦线（中线、角平分线、三分线）长度的终极万能核武器

万能武器 ★★★★★ 线段计算第一定理 含4大举一反三深度推广
📌 【母定理】斯特瓦尔特定理 (Stewart's Theorem)

在 $\triangle ABC$ 中，$D$ 为底边 $BC$ 上的任意一点。记 $BC=a, AC=b, AB=c, AD=d, BD=m, DC=n$（满足 $a = m + n$）。

$$b^2 m + c^2 n = a(d^2 + mn)$$

记忆口诀："A man and his dad put a bomb in the sink." ($man + dad = bmb + cnc$)

🧠 知其所以然：定理推导（邻补角余弦法）
严格推导：邻补角余弦相加为 0

1. 观察底边交点 $D$ 处的两个角 $\angle ADB$ 与 $\angle ADC$，它们互为邻补角：$\angle ADB + \angle ADC = 180^\circ$。

2. 根据三角学恒等式：$\cos \angle ADB + \cos \angle ADC = 0$。

3. 在 $\triangle ABD$ 中由余弦定理：$\cos \angle ADB = \frac{d^2 + m^2 - c^2}{2dm}$。

4. 在 $\triangle ACD$ 中由余弦定理：$\cos \angle ADC = \frac{d^2 + n^2 - b^2}{2dn}$。

5. 两式相加为 0：$$\frac{d^2 + m^2 - c^2}{2dm} + \frac{d^2 + n^2 - b^2}{2dn} = 0$$

6. 两边同时乘以 $2dmn$：$$n(d^2 + m^2 - c^2) + m(d^2 + n^2 - b^2) = 0$$

7. 展开并整理：$$(m+n)d^2 + mn(m+n) = b^2 m + c^2 n$$

8. 代入 $m+n = a$，即得：$$a(d^2 + mn) = b^2 m + c^2 n$$ 证毕！$\blacksquare$

🚀 举一反三：四大深度拓展方向
方向 1：阿波罗尼奥斯中线定理（Apollonius's Theorem —— 最重要的特例）

当点 $D$ 恰好为 $BC$ 的中点时，有 $m = n = \frac{a}{2}$。代入斯特定理：

$b^2 \left(\frac{a}{2}\right) + c^2 \left(\frac{a}{2}\right) = a \left(m_a^2 + \frac{a^2}{4}\right)$
两边同除以 $\frac{a}{2}$：
$$b^2 + c^2 = 2 \left(m_a^2 + \frac{a^2}{4}\right) = 2(AD^2 + BD^2)$$

由此直接导出中线长万能公式：$$m_a = \frac{1}{2} \sqrt{2b^2 + 2c^2 - a^2}$$

方向 2：平行四边形对角线恒等式

在任意平行四边形 $ABCD$ 中，对角线交点 $O$ 互相平分对角线。在 $\triangle ABC$ 中 $BO$ 为中线，套用中线定理立即得到：

$$AC^2 + BD^2 = 2(AB^2 + BC^2)$$

定理口诀：平行四边形两对角线平方和 = 四条边平方和！

方向 3：三中线平方和与三边平方和黄金比（3/4 定理）

将三角形的三条中线公式 $m_a, m_b, m_c$ 全部平方后相加：

$m_a^2 = \frac{1}{4}(2b^2 + 2c^2 - a^2)$
$m_b^2 = \frac{1}{4}(2a^2 + 2c^2 - b^2)$
$m_c^2 = \frac{1}{4}(2a^2 + 2b^2 - c^2)$

三式相加，交叉项完美对称消减：

$$\sum m_a^2 = m_a^2 + m_b^2 + m_c^2 = \frac{3}{4} (a^2 + b^2 + c^2)$$

重心性质：重心 $G$ 分中线为 $2:1$，故各顶点到重心的距离平方和 $\sum AG^2 = \frac{1}{3} (a^2 + b^2 + c^2)$！

方向 4：角平分线长公式的“大一统推导”（斯特定理与角平分线联姻）

如果线段 $AD$ 是角平分线，由角平分线定理 $m = \frac{ac}{b+c}, n = \frac{ab}{b+c}$。将它们代入斯特定理 $b^2 m + c^2 n = a(d^2 + mn)$：

左边 $= b^2 \frac{ac}{b+c} + c^2 \frac{ab}{b+c} = \frac{abc(b+c)}{b+c} = abc$
右边 $= a(d^2 + mn)$
两边消去 $a$：$bc = d^2 + mn \iff d^2 = bc - mn$！

体会大一统的美妙：看似独立的两个定理，在这里完美汇聚！

⚡ AMC 10 真题实战演练
真题示范：已知两边与中线求第三边

【题目】 在 $\triangle ABC$ 中，$AB = 7, AC = 9$，中线 $AM = 7$。求底边 $BC$ 的长度。

【大师解法】：直接套用阿波罗尼奥斯中线定理：

$AB^2 + AC^2 = 2(AM^2 + BM^2)$
$7^2 + 9^2 = 2(7^2 + BM^2)$
$49 + 81 = 2(49 + BM^2) \implies 130 = 98 + 2 BM^2$
$2 BM^2 = 32 \implies BM^2 = 16 \implies BM = 4$
因为 $M$ 是中点，底边 $BC = 2 \times BM = 2 \times 4 = 8$！
